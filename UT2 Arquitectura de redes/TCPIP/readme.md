# Repaso de TCP/IP

[**Abrir el laboratorio interactivo de PDU**](https://alfonsodeuna.github.io/REDES_LOCALES/UT2%20Arquitectura%20de%20redes/TCPIP/)

Actividad para 1.º de SMR: construir la pila TCP/IP de una petición HTTP y su respuesta, y completar los campos Ethernet, IP, TCP y HTTP siguiendo el formato de Packet Tracer.

Incluye datos editables para el profesor, comprobación de respuestas, modo entrega, descarga en texto e impresión de la ficha en blanco o de las respuestas. No envía respuestas a ningún servidor.

También se puede descargar `index.html` y abrirlo sin conexión en un navegador.
