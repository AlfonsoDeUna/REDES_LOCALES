## UT2 · Arquitectura de redes

- [Abrir Dentro del paquete: clase interactiva TCP/IP](https://alfonsodeuna.github.io/REDES_LOCALES/UT2%20Arquitectura%20de%20redes/tcpip-interactivo/)
- [Índice web de la unidad](https://alfonsodeuna.github.io/REDES_LOCALES/UT2%20Arquitectura%20de%20redes/)
- [Guía de uso y edición](UT2%20Arquitectura%20de%20redes/tcpip-interactivo/README.md)

La clase contiene diez secciones con simulaciones de encapsulación y routers, actividades de protocolos y cabeceras, incidentes de seguridad simulados e ICMP. Incluye una propuesta de dos sesiones de 55 minutos, modo Proyector y cuaderno HTML descargable para entregar en Moodle.

Las respuestas y el progreso se guardan en el navegador del alumno; no hay sincronización central ni envío automático al profesor. Las simulaciones no generan tráfico de red real.

Los archivos de esta actividad están en `UT2 Arquitectura de redes/tcpip-interactivo/`. Para editarla, modifica `src/` y ejecuta `python3 build.py` dentro de esa carpeta: se genera `index.html` junto al script, preparado para GitHub Pages y para abrirlo localmente.
