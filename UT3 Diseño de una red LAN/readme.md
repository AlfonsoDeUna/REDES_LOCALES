# UT3 · Diseño de una red LAN

## AD0. Actividad introductoria: visita a un data center de Google

[**Abrir la visita interactiva al data center**](https://alfonsodeuna.github.io/REDES_LOCALES/UT3%20Dise%C3%B1o%20de%20una%20red%20LAN/AD0/)

[Archivos de la web](AD0/)

Sesión introductoria de **55 minutos** para descubrir los elementos físicos de una red y conectar lo observado con el diseño de una red de oficina. Mantiene el mismo estilo visual que AD1.

La actividad incluye cinco fases:

1. **Punto de partida:** dibujo de la red de una oficina y pre-test diagnóstico.
2. **Visita 360°:** vídeo del data center de Google, roles de inspección y ficha de hallazgos.
3. **Conecta las ideas:** selección de preguntas de análisis y conexión con nuestro taller.
4. **Abre el debate:** dos afirmaciones sobre el orden del cableado y los servidores del instituto en la nube.
5. **Ticket de salida:** revisión de las ideas iniciales y propuestas para el proyecto de red.

Las respuestas se guardan localmente en el navegador y se pueden descargar en un cuaderno de texto para entregar. No se envían automáticamente al profesor. En equipos compartidos, descarga el trabajo y borra las respuestas antes de terminar.
